# Using the machine
### It's usually best to let users explore, rather than explaining the whole machine; if you show them how to use it then it often discourages people to use it for themselves, and they'll get the best impact by working out what each part does through experimenting.  
If a user seems confused or overwhelmed, encourage them to insert a question card and push the button. This gives them a quick feel of what's happening, and then they can start exploring from there.

## Example script
If someone asks to know more or would like to be walked through the whole thing, this is an easy script to start from:

> **"This machine is a simple deconstruction of how an AI chatbot like ChatGPT, Claude or Gemini works."**

>>> *Insert a question card and press the button*

> **"You can ask one of these questions, and a small AI chatbot that's running inside the  machine will respond. When we use an AI chatbot however, we're not simply interacting directly with an AI model."**

>>> *Pick up one of the Dataset tubes and plug it in*

> **"Chatbots are made up of huge amounts of data – each of these tubes is a different small AI model which contains information selected and trained in different ways depending on who made it, how big it is and how it was put together. So different models will give us different responses to the same question."**

>>> *Turn the Randomness knob*

> **"Chatbots are more than just data, however. Before we get that response, AI chatbot platforms like ChatGPT will alter the output through lots of hidden settings and conditions which we can't see, such as this one, which changes how much the AI will deliver the 'most likely' responses."**

>>> *Open the Secret Rules door and put one inside*

> **"Chatbots also contain loads and loads of secret rules which they have to follow, and with most chatbot platforms, we never get to know what they are. We can put rules in this box and the chatbot has to try to follow them – *even if the rules contradict knowledge that's contained in the dataset*."**

>>> *Add more rules, see how they alter the responses*

> **"Platforms like ChatGPT might have hundreds of these rules, and some of them are normal things that make sense, like 'Don't use swearwords' or 'Always be helpful'. But some of them might be more suspect – they could say things like 'Don't say anything bad about our company' or 'Always say good things about a certain politician'".**

>>> *Invite the user to have a go for themselves*

> **"This machine shows how easily manipulated the responses of AI chatbots can be, by changing different parts behind the scenes. We can see how easy it becomes to get the chatbot to make mistakes or say things that aren't true."**
