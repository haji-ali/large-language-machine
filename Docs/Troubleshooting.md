# Troubleshooting
## System is hanging or waiting on a blank screen   
Wait up to 60 seconds and the system will auto-reset.

Sometimes a request to the AI model unexpectedly fails. To handle this, there's a timeout which triggers if the button isn't pressed or 60 seconds: a short screensaver animation will play and the system will reset to the "Insert a question card and press GO" screen while clearing its memory.

If this happens repeatedly, perform a [Quick restart](Getting-started.md#quick-restart).

## *Randomness* knob is making a lot of noise when not being used
Transport might have yanked or shifted the cables. Remove the front panel and lightly reposition the wiring.

## Button isn't always firing, only works occasionally
Transport might have yanked or shifted the cables. Remove the front panel and lightly reposition the wiring.

## Button isn't lighting up / isn't working at all
Wait at least 60 seconds to allow the system to reset itself. If it still doesn't work, do a [Quick restart](Getting-started.md#quick-restart), and if you still have issues do a [Full reboot](Getting-started.md#full-reboot-3-min-required).
